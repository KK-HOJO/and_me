# 口コミ返信テンプレート

返信は「感謝 → 共感/具体 → 次回への一言」の3部構成が基本です。
星が低い口コミも、誠実な返信は他の見込み客への信頼材料になります。

## 効果を実感(高評価)（★4〜5）
```
○○様、この度は嬉しいお声をありがとうございます。
お身体の変化を感じていただけて、私たちもとても嬉しいです。
良い状態を保てるよう引き続きサポートいたしますので、
またお気軽にお越しください。IROHA 米子店
```

## 接客・対応への満足(高評価)（★4〜5）
```
○○様、温かいお言葉をありがとうございます。
安心してお過ごしいただけたようで何よりです。
これからも一人ひとりに寄り添った対応を心がけてまいります。
またのご来院を心よりお待ちしております。IROHA 米子店
```

## 清潔感・雰囲気への満足(高評価)（★4〜5）
```

心地よい空間でリラックスしていただけたなら幸いです。
引き続き清潔で落ち着いた環境づくりに努めてまいります。
またお会いできるのを楽しみにしております。IROHA 米子店
```

IROHA 米子店
