# 統一NAP（全媒体でこの表記に揃える）

> NAP（名称・住所・電話）は **全ての媒体で1文字も変えず** に使ってください。
> 表記ゆれ（ビル名の有無・ハイフン種別・全角半角など）はMEO評価を下げます。

## 1行表記
```
and me（アンドミー）｜〒000-0000 東京都渋谷区〇〇1-2-3 〇〇ビル 2F｜TEL 00-0000-0000
```

## ブロック表記（掲載欄・署名用）
```
and me（アンドミー）（アンドミー）
〒000-0000 東京都渋谷区〇〇1-2-3 〇〇ビル 2F
TEL: 00-0000-0000
WEB: https://example.com
```
